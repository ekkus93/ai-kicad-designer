# M2e1 development and regression evidence

This directory contains development evidence for the instance-based M2 schematic
composition remediation. It is not a blind corpus and does not alter the
historical M2 blind evidence.

The three authored probes are:

- `amplifier_to_sallen_key`: a non-inverting gain function feeds a Sallen-Key
  function in the other unit of the same NE5532 package. The expected plan has
  two independent function fragments, one package-power fragment, a signal
  edge from unit A to unit B, and distinct feedback constraints.
- `regulator_parallel_rc`: one L7805 output fans out to two independently owned
  RC fragments and output connectors. The regulator owns only its exact input
  and output support capacitors. Both downstream edges are typed power-flow
  connections and neither requires a connector on the regulator output.
- `dual_timer_led`: two NE555D instances share supply/reference nets, retain
  separate timing/control support groups, and each drives its own LED branch.
  Common rails do not create a signal-order edge between timers.

`tools/make_m2e1_probes.py` deterministically authors these JSON inputs from
reviewed, already-qualified asset and relationship vocabulary. The generated
JSON files are the qualification inputs; the generator never participates in
layout.

## Golden-oracle migration

M2e1 intentionally changes geometry. `tests/test_m2c1.py` and
`tests/test_m2b.py` no longer require new project, SVG, electrical-report, or
layout-report bytes to equal the pre-M2e1 geometry in
`fixtures/m2b/qualification/`. Their replacement authority is:

1. independent electrical comparison from emitted KiCad plus fresh XML;
2. zero KiCad ERC violations;
3. complete independent layout hard gates and metric vector;
4. compiler-owned project byte equality between clean builds;
5. normalized SVG geometry/text equality between clean builds.

The historical qualification files remain untouched and retain their own
integrity tests. No old evidence is regenerated by the M2e1 qualification
runner.

`tools/run_m2e1_qualification.py` runs five clean builds for all 16 known v2/v3
regressions and the three probes, preserving successful and failed artifacts
under `qualification/` and recording normalized reproducibility signatures.
