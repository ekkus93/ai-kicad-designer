# Wires kept out of the op-amp power unit's pin column (2026-11-09)

The designs were generated by `NativeSchematicEngine._compile` (brief v3 power-symbol rails) from the working tree committed as `0b9049ab`. They were then assessed with `NativeSchematicEngine.assess` on this Linux host (KiCad 10.0.6 via `/tmp/AppDir/AppRun`), which is not the locked qualification host.

**Problem:** the NE5532's power unit (U1C) has no drawn body. Rail planning saw only its two pin stubs, so in five accepted drawings of `review_loop_corpus_v3_2026-11-05_qwen35_256k_run1` a ground wire ran across U1C between V+ and V−, over the pin names:

| design | wire across U1C (mm) |
|---|---|
| dual_buffer | (72.39, 41.91)–(87.63, 41.91) |
| inverting_gain | (81.28, 81.28)–(97.79, 81.28) |
| noninverting_gain | (107.95, 95.25)–(124.46, 95.25) |
| rc_to_buffer | (124.46, 71.12)–(140.97, 71.12) |
| sallen_key | (196.85, 71.12)–(213.36, 71.12) |

**Changes in `0b9049ab`:**
- The column between the pins' inner ends of a unit drawn without a body is a routing obstacle.
- A rail plan is invalid if a wire crosses that column or runs along it between the pins (`wires_through_bodyless_units`). A wire that only ends on a pin's inner end, as the compiler draws a local decoupling pair, is allowed.
- The plans that reroute ground mark it with power symbols. The planner's layout check had rejected them because the pre-rail netlist still used the auto-name `Net-(J1-Pin_5)`. The check now names such a net after the power symbol placed on its pin, as KiCad does once the symbol is in the file. The protected observer is unchanged.

**Results:**
- No wire crosses a power unit column in any of the five designs. `assessment.json`: every independent check passes for all five.
- Ground at the decoupling capacitors is now drawn with REF ground symbols instead of the wire across U1C:
  - inverting_gain: 0 → 2 power symbols. `inverting_gain/u1c_closeup_before.png` and `u1c_closeup_after.png` show U1C before and after.
  - dual_buffer: 0 → 1.
  - rc_to_buffer: 0 → 1.
  - noninverting_gain: 1 → 1, rerouted.
  - sallen_key: 2 → 4. Rail planning moved J1 25.4 mm right, as it did before.
- Several of the new REF symbols are drawn sideways because there is no room below the capacitor.
- The other ten corpus designs were regenerated with the same code and are identical to the 2026-11-05 run apart from UUIDs, so they are not repeated here.
- No model review has been run on these drawings yet.
