# Ground symbols drawn pointing down (2026-11-10)

The designs were generated by `NativeSchematicEngine._compile` (brief v3 power-symbol rails) from the working tree committed with this README. They were then assessed with `NativeSchematicEngine.assess` on this Linux host (KiCad 10.0.6 via `/tmp/AppDir/AppRun`), which is not the locked qualification host.

**Problem:** in the accepted inverting_gain drawing of `review_loop_corpus_v3_2026-11-10_qwen35_256k_run1`, C2's REF ground symbol pointed sideways, left, at (99.06, 82.55). The owner asked for it to be fixed. There were two causes:
- **Sort order.** At one point, placement options were ordered by the raw direction tuple, so left (−1, 0) was always tried before down (0, 1).
- **No room for the name.** U1C's V− wire runs 3.81 mm below C2's ground pin. That leaves room for the downward glyph but not for "REF" written under it.

**Changes:**
- **Direction preference.** A ground symbol is tried pointing down before any sideways direction, at every candidate point of the same stub class.
- **Name beside the glyph.** If down fits but the name under the glyph does not, the name is written beside the triangle, right first and then left. This is ranked after every placement with the name below.
- **Scope.** Supply symbols keep their previous placements. A broader version also turned VMINUS arrows upright, and in sallen_key one landed in U1C's pin column, so that version was dropped.
- **Pin column.** Power-symbol clearance no longer releases a bodyless unit's pin column when the symbol sits on one of that unit's pin inner ends.
- **Field position.** Clearance checks now read the Value field position from the file instead of recomputing it.

**Results:**
- All 15 corpus designs were regenerated, and every independent check passes for all of them. `assessment.json` is included for the three designs that changed.
- inverting_gain: C2's REF now points down, with the name to its right (`closeup_before.png`, `closeup_after.png`). U1C's reference and value moved down beside its pins, into the space the sideways REF text used to fill.
- reference_555_led_flasher_v8: C2's REF at (71.12, 45.72) now points down instead of left.
- sallen_key: the sideways REF at C2 (214.63, 69.85) is gone. That ground group is marked by a downward REF under C3 at (116.84, 97.79).
- The other twelve designs are identical to the 2026-11-10 corpus run apart from UUIDs.
- No model review has been run on these drawings yet.
