# Decoupling capacitor moved beside its pin (2026-11-11)

The designs were generated by `NativeSchematicEngine._compile` (brief v3 power-symbol rails) from the working tree committed with this README. They were then assessed with `NativeSchematicEngine.assess` on this Linux host (KiCad 10.0.6 via `/tmp/AppDir/AppRun`), which is not the locked qualification host.

**Problem:** in inverting_gain from `return_rail_symbols_2026-11-11_run1`, C2's VMINUS wire left U1C pin 4 at (82.55, 86.36), ran right under C2 and back up to C2's top pin at (99.06, 74.93): 40.64 mm. C2's REF ground symbol sat 1.27 mm above that wire. An outside review flagged the area as the drawing's weakest spot.
- **Symbols instead of the wire:** replacing the pair's wire with VMINUS symbols is not possible. The protected layout observer rejects a decoupling pair without an explicit wire path ("observed local motif lacks explicit wire path: decoupling").
- **Root cause:** the loop exists only because of where the composer placed C2.

**Change (approved by the owner):** a new step, `straighten_decoupling_text`, runs at the start of rail planning.
- **Trigger:** a capacitor in a declared decoupling pair whose wire is longer than the direct distance to its consumer pin.
- **Move:** the capacitor is moved so that its paired pin sits level with the consumer pin's end, beside it, 5.08 to 25.4 mm away, with its body extending the way that pin points. The nearest position wins.
- **Acceptance:** the move stands only if the pair's wire becomes one straight run and the protected layout check accepts it. The drawing is then observed again and the rails are planned as before.
- **Limits:** only translation is supported. A capacitor that would need to be flipped is left alone.
- **Power flags:** the move reroutes the moved part's nets, and it now treats power-flag pins as fixed terminals. Without that, the REF reroute cut J1's REF flag off, and ERC failed.

**Results:**
- All 15 corpus designs were regenerated, and every independent check passes for all of them.
- Only inverting_gain changed. It was the only design whose decoupling wire detoured. The other fourteen are identical to their latest evidence apart from UUIDs.
- inverting_gain:
  - C2 moved 11.43 mm left and 11.43 mm down. Its VMINUS wire is a straight 5.08 mm from pin 4.
  - C2's REF hangs straight down below it.
  - Total wire length went from 245 to 210 mm, and the closest text-to-wire distance from 1.40 to 3.17 mm.
  - See `drawing_before.png`, `closeup_before.png` and `closeup_after.png`.
- inverting_gain also has two trade-offs:
  - "U1C / NE5532" sits beside the unit, not above pin 8. With VPLUS pointing right from pin 8, the independent owner-association measure reads text above pin 8 as belonging to the VPLUS symbol (2 witnesses, against 0 beside the unit). The owner chose to keep the text beside the unit.
  - The VMINUS arrow points up from C2's top pin, so its text sits next to U1C's V− pin name. Every check passes.
- No model review has been run on this drawing yet.
