# Return rails drawn with ground symbols instead of long wires (2026-11-11)

The designs were generated by `NativeSchematicEngine._compile` (brief v3 power-symbol rails) from the working tree committed with this README. They were then assessed with `NativeSchematicEngine.assess` on this Linux host (KiCad 10.0.6 via `/tmp/AppDir/AppRun`), which is not the locked qualification host.

**Problem:** an outside review of inverting_gain from `supply_rail_symbols_2026-11-11_run1` found three remaining issues:
- a long REF wire from J1 to U1A's + input
- C2's ground wired by a loop over U1C
- the closest text-to-wire distance down to 0.635 mm (from 1.27 mm), where that loop ran just under "NE5532"

The earlier change capped only supply rails, so REF kept the old wire-everything rule.

**Change (approved by the owner):** the 25.4 mm cap now applies to every asserted rail, including return rails (`MAXIMUM_SUPPLY_ROUTE` is renamed `MAXIMUM_RAIL_ROUTE`). Groups farther apart get ground symbols, drawn pointing down where they fit, and the planner reroutes every rail. Local pairs, such as a decoupling capacitor to its pin, and power-flag paths stay wired.
