# Good Reference Designs

Add a small curated set of KiCad projects that you own or are licensed to redistribute and that you personally consider strong examples of human-readable schematic/PCB design.

Prefer roughly 5-8 examples spanning different topology classes rather than a large random corpus. For each example, include the KiCad source files, rendered schematic/board images when practical, and a short `NOTES.md` explaining what makes the design/layout good.

Useful diversity includes: analog/op-amp, regulator/power, MCU/minimal system, USB/digital interface, sensor/bus, and connector-heavy designs.

Do not add the old `model_kicad_files/` corpus here until its source provenance and redistribution licenses are resolved.
